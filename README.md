# StayMiles

🏡 AI-Powered Accommodation Booking Platform

StayMiles is a full-stack accommodation booking platform that allows users to explore, review, and manage accommodations with AI-enhanced insights for smarter booking decisions.

## ✨ Features

• Secure Authentication & Authorization  
• Create, Update, Delete & Manage Listings  
• Review & Rating System  
• AI-Powered Review Summarization  
• Safety Score Generation from Reviews  
• Nearby Insights (Food, Transport, Medical, Grocery)  
• Transparent Price Breakdown  
• Cloudinary Image Uploads  
• RESTful API Architecture  
• Robust Error Handling & API Fallback Mechanism

## 🛠️ Tech Stack

**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose  
**Frontend:** EJS, JavaScript, CSS  
**Cloud & APIs:** Cloudinary, Google Gemini API  
**Authentication:** Sessions, Cookies, Authorization Middleware
